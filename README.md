# Moby × KOPI — демо

Демо-прототип банковского приложения в стиле Moby со встроенной копилкой [KOPI](https://github.com/jimparkby/mtb): каждая оплата картой округляется вверх, сдача копится и одним пакетом покупает BTC, ETH или консервативный рублёвый инструмент по реальному курсу.

Всё работает в браузере, бэкенд не нужен: это статический сайт, который деплоится на Vercel как есть. Логика копилки та же, что в [jimparkby/mtb](https://github.com/jimparkby/mtb), плюс счёт карты: остаток, пополнения и лента операций.

## Экраны

Референсы интерфейса лежат в [`docs/screens`](docs/screens).

| Экран | Что в демо |
|-------|------------|
| **Главная** | Имя, карта Prime Line BYN, остаток (скрывается «глазом»), кнопки Пополнить / Перевести / Оплатить, последняя операция, баннер «Копилка KOPI» с живой суммой портфеля, промо «Округляй и копи», счёт KOPI с доходностью |
| **Оплатить** | Шторка-эмулятор кассы: пресеты покупок, чек «покупка → округлено → списано → в копилку». С карты списывается покупка вместе со сдачей |
| **Пополнить** | Шторка пополнения карты (эмулируется) |
| **Продукты** | Карусель баннеров, Карты и счета, Кредиты, Вклады, **Инвестиции со сдачи** (NEW), Заявки на продукты |
| **Чат** | Чат-помощник: отвечает про копилку, округление, курс BTC/ETH, баланс и цель по данным пользователя |
| **Ещё** | Настройки (настройки копилки), Уведомления, Курсы валют (живой BTC/ETH/USD), KOPI, Обменник, О демо |
| **Копилка KOPI** | Портфель с графиком за час и бейджем Live, копилка и «Купить сейчас», цель с прогнозом, история округлений и покупок |

Прямые ссылки для QR: `#kopi`, `#pay`, `#topup`, `#products`, `#chat`, `#more`, `#rates`.

Данные каждого посетителя хранятся у него в браузере (localStorage), поэтому весь зал по QR может нажимать одновременно, не мешая друг другу. «Начать демо заново» в настройках копилки возвращает исходную неделю покупок и остаток.

## Как устроено

| Файл | Что делает |
|------|------------|
| `public/engine.js` | round-up движок: округление, множитель, количество актива, прогноз цели |
| `public/bank.js` | демо-банк: счёт карты, оплаты (списывают покупку и сдачу), пополнения, копилка, пакетная покупка по текущему курсу, цель, сброс к неделе Ивана. Данные — в `localStorage` |
| `public/rates.js` | живой курс прямо из браузера: Dzengi (BTC/BYN, ETH/BYN, резидент ПВТ) → OKX → Kraken → Coinbase → CoinGecko × курс НБРБ. Обновление каждые 5 с, при недоступности — последний известный курс |
| `public/app.js` | интерфейс: экраны, шторки, чат-помощник, уведомления |

Все суммы — в копейках (целые числа). Покупка «бумажная»: записывается по реальному курсу площадки, ордер никуда не уходит.

## Запуск

```bash
npm start   # http://localhost:3000 — просто раздаёт public/
npm test    # тесты движка, банка и курса
```

Зависимостей нет, нужен только Node.js для локального просмотра и тестов.

## Деплой на Vercel

`vercel.json` уже настроен: без сборки, раздаётся папка `public`. Импортируйте репозиторий на vercel.com → Deploy.
